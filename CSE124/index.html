What is our project?
Disaster Route Optimizer

During emergencies like earthquakes, fires, or floods, saving time means saving lives. Our web application helps administrators manage disasters and send rescue teams quickly — built to apply real-world Data Structure concepts.

Real-Time Firebase AI Integrated Graph Routing
🌊
The Problem
In disaster scenarios, rescue coordination is slow. Teams get stuck on blocked roads, priorities are unclear, and response time is critical.
⚡
Our Solution
A live map dashboard where admins place disasters and teams, block roads, and let the system find the fastest safe route — instantly.
🎓
Academic Goal
Demonstrate Stack, Priority Queue, Graph, Dijkstra's Algorithm, and Tree in a working real-world system.

Disaster Management
Stack & Priority Queue

Multiple disasters are managed simultaneously using two data structures. Emergency cases use a Stack (LIFO) for instant critical response, while all other cases are sorted by a Priority Queue (Min-Heap).

EMERGENCY→ Stack (LIFO) — immediate
HIGH→ Priority Queue — top
MEDIUM→ Priority Queue — mid
LOW→ Priority Queue — base

Routing Algorithm

        
Graph & Dijkstra

        

        
The entire map is modeled as a Weighted Graph. Road intersections are nodes, roads are edges. Dijkstra's Algorithm computes the shortest rescue path instantly.

        

          
Nodes represent road intersections on the map

          
Edges represent roads with distance weights

          
Road Block removes the edge from the graph

          
New shortest path is recalculated instantly

Challenges

        
Current Limitations

        

        

          

            
⏱️

            
API Latency
The free OSRM routing API sometimes takes a few seconds to return path data, causing minor delays in route display.

          

          

            
📱

            
No Mobile App
Currently web-only. Field rescue teams need a dedicated mobile interface for on-ground use.

          

          

            
📍

            
No GPS Tracking
Rescue team positions are manually placed — live GPS movement tracking is not yet integrated.

          

          

            
🤖

            
No Automated Assignment
Admins must manually assign rescue teams to disasters. The system does not yet automatically dispatch teams based on live data.

          

        

      

      

        
        

          

            
⚠️ Impact Summary

            
    
              
  • Performance — API delays in critical moments
    • 
              
  • Accessibility — no field-friendly mobile interface
    • 
              
  • Tracking — team locations are not live
    • 
              
  • Coordination — no multi-admin support
    • 
            

          

          

            
Scope of This Version

            
This is a prototype built for academic purposes to demonstrate data structure concepts. Production deployment would require addressing all limitations.
